# SWADE Weapon Properties

A Foundry VTT module for **Savage Worlds Adventure Edition (SWADE)** that adds additional weapon properties for use with custom weapons, setting rules, and equipment.

Properties are applied through Foundry **Active Effects**, allowing them to be added to individual weapons or actors without replacing SWADE's normal weapon and combat systems.

## Compatibility

Currently developed and tested with:

* **Foundry Virtual Tabletop:** Version 14
* **Savage Worlds Adventure Edition:** Version 6.0.4

Earlier versions of Foundry VTT and SWADE are not currently supported or tested.

# Weapon Properties

## Brutal

**Brutal** modifies the way damage dice behave.

Normally in SWADE, damage dice **Ace** when they roll their maximum value. The maximum result is kept and the die is rolled again. If the new result is also the maximum, it Aces again, continuing until a non-maximum result is rolled.

Brutal adds an additional rule:

> When a Brutal damage die rolls a **1**, the 1 is discarded and the die is rolled again. If another 1 is rolled, it is discarded and rolled again, continuing until the die rolls something other than 1.

Brutal does **not** replace normal SWADE Acing. The two mechanics interact normally.

For example, on a Brutal d6:

```text
1 → 1 → 4
```

The two 1s are discarded, for a final result of **4**.

```text
6 → 1 → 4
```

The 6 Aces, the 1 is discarded, and the 4 is retained, for a final result of **10**.

```text
1 → 6 → 6 → 1 → 3
```

The first 1 is discarded, both 6s Ace, the second 1 is discarded, and the 3 ends the chain, for a final result of **15**.

### All Damage Dice Are Brutal

When Brutal is active for a damage roll, it applies to **all dice contributing to that damage roll**, not just the weapon's base damage die.

This includes:

* Weapon damage
* Strength damage
* Raise/Bonus Damage
* Conviction damage
* Additional damage dice added through modifiers
* Other bonus damage sources

Brutal also remains active when damage is rerolled using a **Benny** or **Free Reroll**.

### Brutal Active Effect

Add the following change to an Active Effect:

```text
Attribute Key: flags.swade-weapon-properties.brutal
Change Mode:   Override
Effect Value:  true
```

Brutal dice are displayed in the Foundry damage roll with the `rr1` modifier.

For example:

```text
1d6xrr1
```

Here:

* `1d6` is the damage die.
* `x` represents normal SWADE Acing.
* `rr1` represents the Brutal reroll behavior.

The module handles the interaction between Acing and Brutal internally, allowing a maximum generated by a Brutal reroll to Ace and a 1 generated by an Ace to trigger Brutal.

## Light

**Light** allows a weapon to be used in the off hand without suffering SWADE's normal **−2 Off-Hand Penalty**.

Light affects only the weapon carrying the property.

For example, a character wielding a normal weapon in their main hand and a Light weapon in their off hand suffers no Off-Hand Penalty when attacking with the Light weapon.

### Light Is Not Ambidextrous

Light does **not** grant the character the **Ambidextrous** Edge or set SWADE's Ambidextrous flag.

This distinction is important because Ambidextrous has other effects within SWADE.

In particular, Light does **not** allow a character to combine Parry bonuses from multiple weapons.

A non-Ambidextrous character wielding two weapons that each grant +1 Parry still receives only the normal +1 Parry, even if one or both weapons are Light.

If the character actually has Ambidextrous, SWADE handles its normal additional effects independently.

### Light Active Effect

Add the following change to an Active Effect on the weapon:

```text
Attribute Key: flags.swade-weapon-properties.light
Change Mode:   Override
Effect Value:  true
```

While the effect is active, that weapon ignores the −2 Off-Hand Penalty.

Other attack modifiers and weapon behavior remain unchanged.

# Combining Properties

A weapon may have more than one property.

For example, a weapon may be both:

```text
Brutal
Light
```

by having both Active Effect changes:

```text
flags.swade-weapon-properties.brutal = true
flags.swade-weapon-properties.light = true
```

Each property operates independently.

# Installation

## Manifest Installation

In Foundry VTT:

1. Open **Add-on Modules**.
2. Select **Install Module**.
3. Paste the module's manifest URL into the **Manifest URL** field.
4. Select **Install**.

Manifest URL:

```text
https://github.com/bigbadbuffalo/swade-weapon-properties/releases/latest/download/module.json
```

After installation, enable **SWADE Weapon Properties** from **Manage Modules** inside your SWADE world.

## Manual Installation

Download the module release and place the `swade-weapon-properties` folder inside:

```text
FoundryVTT/Data/modules/
```

Restart Foundry VTT and enable **SWADE Weapon Properties** from **Manage Modules**.

# Reporting Bugs

Please report problems through the project's GitHub Issues page:

```text
https://github.com/bigbadbuffalo/swade-weapon-properties/issues
```

When reporting a problem, please include:

* Foundry VTT version
* SWADE system version
* Property or properties being used
* Relevant weapon configuration
* Any relevant Active Effects
* A screenshot of the roll or behavior, if applicable

For Brutal damage issues, it is also useful to include:

* Damage formula
* Whether a Raise was used
* Whether Conviction was active
* Any additional bonus damage dice
* Whether the damage was rerolled with a Benny or Free Reroll
